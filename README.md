📦 XYZ Fulfillment Dashboard
A simple Streamlit-based fulfillment dashboard designed to help an e-commerce business monitor orders, inventory, priority shipments, and fulfillment issues in one place.

Features
📊 Order status and fulfillment overview

🔴 Priority order monitoring

📦 Main and backup warehouse inventory tracking

⚠️ Low-stock and inventory issue identification

📋 Order filtering by fulfillment status

🚚 Courier and fulfillment analysis

📈 Interactive charts using Plotly

Tech Stack
Python

Pandas

Streamlit

Plotly

Project Goal
The application addresses common fulfillment problems such as missed priority orders, inventory shortages, and lack of visibility into order status. It provides a simple interface that warehouse and office teams can use to identify issues and take action quickly.
